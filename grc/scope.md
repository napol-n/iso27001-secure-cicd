# ISMS Scope

## Organization

NovaTech is a fictional software company that develops and operates
a Python-based customer web application.

## In-Scope System

Customer Web Application

## In-Scope Components

- Source code
- GitHub repository
- CI/CD pipeline
- Application dependencies
- Development process
- Deployment process

## Technology

- Python
- Git
- GitHub
- GitHub Actions

## ISMS Scope Statement

The scope of this project covers the software development and CI/CD
process used to manage, test, and deploy the NovaTech customer application.
